# Platform glossary

> Scope: Platform terms. Identical in every project and owned by the platform team. Do not edit or adapt it inside a project.  
> Owner: Platform team

Terms used in `knowledge.md` and in the `coding-guidelines.md` of the `apply-coding-guidelines` skill. Project-specific terms belong in `.ai/project/glossary.md`.

| Term                 | Definition                                                                                                              |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Configurator         | The Combeenation configurator a project is linked to. Custom code runs inside it.                                       |
| Custom code          | Project code that is bundled into `cfgr.js` and runs inside the configurator.                                           |
| Custom code SDK      | `@combeenation/custom-code-sdk`. Connects custom code to the configurator (`ValueComponent`, `CustomControl`, `Panel`). |
| Entry point          | `src/index.ts`. Runs once the configurator is ready.                                                                    |
| `cfgr.js`            | The build output: a single ES module without extra chunks, uploaded on the platform.                                    |
| `cbn.config.json`    | Project file that links the project to a company and a configurator.                                                    |
| `ValueComponent`     | Typed handle for a configurator component. Reads, writes and subscribes to its value.                                   |
| `CustomControl`      | A control in the configurator that gives custom code a DOM element to render into.                                      |
| `Panel`              | Typed handle for a configurator panel.                                                                                  |
| Generated typings    | `src/typings/cfgr-defs.generated.ts`. Generated by the connected dev server instance. Never edited by hand.             |
| Sync plugin          | `@combeenation/vite-plugin-custom-code-sync`. Connects the project to the platform and provides the generated typings.  |
| 3D viewer            | `@combeenation/3d-viewer`. Renders a 3D scene on a canvas and re-exports Babylon.js types.                              |
| Platform description | The reference files of the `combeenation-cpq` skill (`knowledge.md`, `glossary.md`). Read-only in a project.            |
| Project description  | The files in `.ai/project/`. Maintained per project.                                                                    |
